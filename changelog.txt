MacMCP Changelog
================

Tagged release history is summarized from Git commits. Repetitive release
bookkeeping commits (Cask/formula pointer updates and publication commits) are
folded into the corresponding release. The Unreleased section describes the
current working-tree changes and must be moved into a dated version section
before publication.

Unreleased
----------

No unreleased changes.

0.2.26 - 2026-09-10
-------------------

- Add the integrated one-page MacMCP Settings window for login, local and
  tunnel access, EventKit, mail accounts, updates, logs, and repository links.
- Add mail-account add, edit, remove, provider validation, multiple-account
  support, and per-account read-only/draft controls.
- Add tunnel configuration with validation and direct links to tunnel and
  ChatGPT custom MCP documentation.
- Simplify the status-bar menu to `Open Settings...` and `Quit`.
- Sign the local CLI with the same configured Developer ID identity as the app
  to avoid repeated Keychain authorization prompts.

0.2.25 - 2026-09-10
-------------------

- Add a Homebrew-free, administrator-free drag-and-drop DMG installation path.
- Add first-launch setup for optional Mail and/or ChatGPT tunnel configuration;
  allow Mail-only, tunnel-only, both, or neither.
- Bundle the signed OpenAI `tunnel-client` and its official companion files in
  the release app so tunnel setup does not require Homebrew or a separate CLI.
- Add menu controls for `Calendar > Allow MCP access` and
  `Reminders > Allow MCP access`, persisted and applied immediately to local
  MCP and ChatGPT tunnel traffic.
